# Callzo Software Engineer Intern Assessment

Two independent projects, one folder per task:

- `task1/` — FastAPI + PostgreSQL webhook metering service.
- `task2/` — React + Tailwind + Recharts usage administration console.

Read each folder's README for architecture, failure behavior, run instructions and submission notes. Task 1 runs with `docker compose up --build`. Task 2's Compose file references a prebuilt public image as required by the evaluator; build and push it using the instructions in `task2/README.md` after replacing the Docker Hub namespace.
